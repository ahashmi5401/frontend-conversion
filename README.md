**Project Overview**

**MyBindle** is a **front-end web** project designed to showcase a social networking interface.
It includes **hero sections, feature cards, testimonials**, install steps, and download sections with responsive design.

The project was converted from a Figma design into a responsive web page using Tailwind CSS and custom JavaScript for interactions like dark mode toggling.

Features

Fully responsive design for desktop, tablet, and mobile. //pending 

Interactive hero section with **CTA buttons**.

Feature cards showcasing key app features.

**Testimonials** section with fade effect.

Install steps section for app onboarding.

Download section with App Store and Play Store buttons.

Dark mode toggle implemented with JavaScript.

SEO-friendly and optimized for performance using Lighthouse/PageSpeed Insights recommendations.

##Installation

Clone the repository:

git clone https://github.com/yourusername/mybindle.git


Navigate into the project folder:

cd mybindle


Open index.html in your browser.

No backend or build steps required, fully front-end static website.

Usage

Click “Get Started” to simulate CTA interactions.

Toggle Dark Mode using the button in the navbar.

Explore Features, Testimonials, and Download sections for layout and design reference.
